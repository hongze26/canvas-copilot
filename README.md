# Canvas Copilot

将自己的 Canvas 课程整理成按教学周归档的本地资料库，保存原文、制作中文学习版，并汇总新增资料、待办和截止时间。

[项目仓库](https://github.com/hongze26/canvas-copilot) · [技能说明](SKILL.md)

项目名为 **Canvas Copilot**，技能调用名为 **`canvas-study`**。课程、学校、时区和教学周在首次使用时根据使用者自己的 Canvas 与正式日程确定。

## 功能

- 从 Dashboard 和全部课程识别当前在修课程，按用户指定范围扫描。
- 对照来源和库存识别新增资料，保存附件与网页正文，保留原始文件。
- 在当前对话中制作中文学习版，保留公式、图表、题号和必要专名。
- 按实际教学安排维护 Week 目录、课程索引、资源库存和扫描记录。
- 汇总作业要求、待办和截止时间；获得授权后，通过 Gmail 向本人发送扫描汇总。
- 首次扫描附教学计划，后续周一扫描附当周安排；暂停后可从已有记录接续。

## 环境要求

| 能力 | 用途 |
| --- | --- |
| 能加载 `SKILL.md` 的 AI 助手 | 执行技能流程；下文提供 Codex 本地安装方式 |
| 本地文件读写工具 | 保存资料、译文、导航及状态 |
| Python 3 | 运行项目初始化脚本，仅使用标准库 |
| 已授权的浏览器或 Canvas 连接器 | 访问本人课程及下载附件；登录与多因素验证由本人完成 |
| PDF 提取、中文排版与渲染工具 | 制作并检查 PDF 中文学习版 |
| Gmail 连接（可选） | 经用户授权发送扫描汇总 |

扫描、下载、翻译和发送由助手调用所在环境的工具完成。初始化脚本只创建本地模板文件。安装技能不会安装这些工具、连接账户或授予发邮件权限。

## 安装到 Codex

将本仓库内容放入个人技能目录下的 `canvas-study` 文件夹。已安装 Git 时，可在终端运行：

```sh
git clone https://github.com/hongze26/canvas-copilot.git "$HOME/.agents/skills/canvas-study"
```

也可以下载仓库 ZIP，将包含 `SKILL.md`、`agents/`、`assets/` 和 `scripts/` 的整层目录复制到该位置。最终应能找到 `.agents/skills/canvas-study/SKILL.md`，避免多套一层仓库目录。

已有同名技能时，先检查自己的修改，再决定如何更新。Codex 通常会自动发现技能；没有出现时重启 Codex。目录规则见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。

## 首次使用

1. 新建一个独立的课程资料目录，在助手中打开该目录。
2. 在助手实际使用的浏览器中登录自己的学校 Canvas，准备好文件读写和 PDF 工具。
3. 发送下面的指令，入口不明确时附上学校 Canvas 网址：

```text
请使用 $canvas-study 初始化当前资料目录，从我已登录的 Canvas 识别当前在修课程，
保存原文、制作完整中文版并按教学周归档，更新索引和库存。
入口、时区或当前教学周无法确定时再问我。本次不发邮件。
```

需要扫描邮件时，连接自己的 Gmail，并单独明确授权，例如：

```text
我授权每轮扫描结束后，通过我自己的 Gmail 向本人 me 发送扫描汇总。
首次附教学计划，后续周一扫描附当周安排。
```

助手会核实已连接账户与收件意图。邮件正文与发送回执保存在使用者的课程资料目录中。

## 日常使用

在已有课程资料目录中发送：

```text
使用 $canvas-study 继续扫描，遵守本项目已有规则与授权，从现有记录接续。
```

可进一步指定“只扫描某门课”“只翻译已下载资料”“本次不发邮件”或“暂停”。扫描默认手动触发，周一安排随当次扫描汇总提供。

## 手动初始化与测试

在本仓库根目录运行下面的命令，将 `../my-canvas-archive` 替换为自己的课程资料目录：

```sh
python scripts/init_project.py --project ../my-canvas-archive
```

新目录会创建 10 份基础文件，包括课程配置、归档流程、课程总索引，以及空白库存和邮件发送记录。检测到已有项目标志时返回 `existing_project` 并保留已有文件。该命令只完成目录初始化；后续扫描仍需由助手执行。

初始化脚本的测试命令为：

```sh
python -B -m unittest discover -s scripts -p test_init_project.py
```

测试覆盖空白项目初始化、库存与邮件记录为空、重复运行保留用户修改，以及已有课程索引时的项目保护。

## 隐私与使用范围

技能分发文件包含流程、脚本和空白模板。实际使用后，课程目录会包含个人课程配置、下载内容、扫描记录，以及按授权生成的邮件正文和回执；这些文件应保留在自己的资料目录中。

读取到的课程内容会进入当前 AI 助手的处理流程，适用其服务与连接器的数据政策。翻译在当前对话中完成，不调用独立的外部翻译服务；文件保存在本地并不代表整个流程离线运行。登录密码、多因素验证码和浏览器会话由使用者自行管理。

课程资料按自己的访问权限和课程要求使用。分享项目时，仅分发技能与空白模板；教师课件、教材、个人作业及使用后的账户和课程记录另行保管。提交 Issue 或改进建议时，使用虚构示例，去除截图与日志中的个人信息。

## 限制

- 在线扫描依赖所在环境实际提供的访问和下载能力，以及学校 Canvas 的页面结构；缺少访问能力时可整理已有本地资料。
- PDF 制作和邮件发送依赖对应工具。缺少工具时保留文本或待发正文，记录未完成事项。
- 日期和教学周以已发布的正式日程为依据；无法确定或发生冲突时列为待确认。
- 测验仅查看入口与说明，作业仅整理要求和截止时间；不代为作答或提交，不推断作业完成状态。
- 其他助手平台需按其工具能力和技能格式适配，本仓库提供的是标准技能目录。
