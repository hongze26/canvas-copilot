# Canvas 扫描邮件通知

## 触发

取得用户对每轮扫描结束后给本人发邮件的授权后，每轮手动扫描收尾发一封中文邮件；无新增或部分完成也发。用户要求暂停时先停止，继续后收尾。周报只随周一扫描触发，不创建定时任务。每人连接自己的Gmail并核实账户，收件人设`me`；连接账户变化时先核实收件意图。

## 内容

主题含本地日期时间、教学周、首次教学计划/扫描汇总/本周安排，以及新增数量/无新增/部分完成。新增数量按唯一教学资源计，原文与译文不重复计，来源说明不另算教学资源。

正文包含实际扫描范围；逐课资料名称、适用周、原文/中文保存状态和HTTPS来源链接；具体行动、相关deadline及来源；教学计划或周一安排；集中列出的待确认和未完成事项。已检查无新增、未检查与访问失败分别说明，视频只存入口须注明。本地路径作为电脑查找位置，不能伪装成邮箱可下载附件。

正式提交期限、材料发布时间、课堂安排与建议完成时间分开标注。日期按课程配置时区处理，使用该日期实际时区偏移；不要固定UTC偏移。无具体时间就标时间未公布，只有日期则保留日期粒度。重要但本轮未复核的期限保留最后核实日期；冲突日期并列来源，不能擅改年份。

过期项目单列，不能当未来待办。没有用户说明或已获授权的可见证据，完成/提交状态写未核实；不从View results、截止已过或本地无作业推断状态。测验只读说明，不开始、不作答、不提交、不查看结果；Grades只存入口。

## 首次和周一

- 扫描前无有效扫描历史：首次邮件逐课给出截至当前可见的教学计划、周数分配、当前周、已排课主题和后续已公布安排，包含两周一组、Reading Week与项目阶段；未知处写未公布。旧资料首次归档不算刚发布。
- 有历史但首次启用邮件：可发“功能启用与已有教学计划”基线，注明最近扫描日期与本轮是否访问Canvas，不把历史资料算当日新增。
- 后续周一扫描：按扫描结束时当地日期，列该周周一至周日的教学主题、已公布课堂/实验/测验/提交节点和按截止排序的建议。无安排不编造。同一天多次独立扫描均附当周简表。
- 其他后续扫描：增量、待办及已知期限即可。首次恰为周一时，一封兼含首次计划和当周安排。

计划使用正式课表、公告、作业和既有资料；仍遵守当前周教学页访问上限，不为预告打开未来教学附件。

## 保存、发送与补发

先读取当轮扫描和来源记录、有关日程、`Canvas邮件记录/发送记录.json`。每轮以扫描记录名为标识；续扫沿用标识，已有成功回执的同一轮不重发，新的独立扫描仍发。功能启用使用独立标识。

先将HTML转义后的正文存为`Canvas邮件记录/轮次标识.html`，通过当前环境的Gmail工具发给`me`，使用UTF-8 text/html。成功才向发送记录数组追加轮次、扫描路径、类型、收件人、主题、正文路径、发送时间（含时区偏移）、sent状态和message ID；有thread ID也保存。不声称收件人已读。

明确失败记failed，保留同一正文、简短错误，恢复连接后补发。结果不明记unknown，先查已发送邮件中该主题与时间再决定是否重发。发送失败不回滚归档；对话交付中说明邮件结果。缺少邮件工具时保存正文并说明仍未发送。
