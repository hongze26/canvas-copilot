# 课程学习资料工作约定

本项目用于用户自己的Canvas课程归档与中文学习资料整理。开始前完整读取课程配置.md、Canvas每日扫描计划.md、Canvas检索与归档步骤.md、Canvas扫描周次规则.md、课程资料归档流程.md和Canvas扫描邮件通知.md，再读课程资源目录、已有课程Resource Index.md、当前库存和最近扫描记录。

首次运行从用户已登录的Canvas识别当前在修课程，自动补全课程配置并按课程名称/代码创建文件夹和索引；每位使用者的选课独立，不预设专业或课程名单。入口、时区或当前教学周无法确定时才集中询问缺失信息，同时继续可确定的常设信息归档。

默认“扫描增量 → 保存原文 → 制作中文版 → 按周归档 → 更新索引与库存 → 核对文件和链接 → 发给本人扫描邮件”。根据用户指定范围执行；暂停时立即停止，继续后接续进度。仅手动扫描。

日常新建资料、中文排版、周次索引和库存维护、本地链接修复直接执行。原始资料不删除、不覆盖；已有教学正文或用户作业的内容修改先记录，等待用户同意。目录维护不授权改写教师要求。

取得用户对每轮扫描结束后给本人发邮件的授权后，扫描结束直接调用已连接Gmail向me发送一封汇总，不逐次询问。首次附教学计划与周次分配；后续周一扫描附当周安排。没有连接时保留正文并告知；收件账户变化先核实。

翻译在当前对话内完成，不使用外部翻译服务。PDF使用可用的PDF技能，完成渲染检查。区分建议与教学要求、资料发布时间与提交期限；不推断用户是否完成作业，不启动或提交测验，Grades仅保存入口。
