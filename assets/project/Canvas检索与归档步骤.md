# Canvas 检索与归档步骤

1. 先查本地课程索引、周次资料清单、历史来源与库存，按URL和Canvas ID识别同一资源。
2. 打开课程Modules，展开已发布模块，只访问当前周以内教学页。逐项读取正文与相关课件、实验代码、数据、录像、练习和附件链接，不能只看模块列表。
3. 检查实际开放的Announcements、Pages、Files、Assignments、Quizzes、Discussions、Reading List、Student Support等常设栏目，翻页或加载更多。作业查看完整详情、附件、提交要求、评分表和截止时间。测验只读入口与说明；Grades只存入口。
4. Reading List内嵌空白时等待内容或打开页面已给出的外部书目链接；明确记录错误，不能把加载失败记为无资料。
5. 下载前监听下载事件，点击下载，取得完成后的实际路径，再复制归档。检查类型、非空及可读性；同名不同资料加日期/ID，保留旧文件。
6. 页面保存可读原文与来源URL；已下载附件改成本地链接。视频不能下载时只存可播放入口，注明是否下载/转录。
7. 每条来源记录包含课程、适用周、标题、类型、URL、可见ID、更新时间（有则记录）、本地相对路径和状态。相同资源复用一份，保留多个引用入口。变化仅另存差异，等待用户决定旧正文修改。
8. 更新索引与库存，保存Canvas扫描记录下的轮次Markdown及-sources.json；下载/翻译/访问待办分别标明。按邮件规则发送并记录结果。
