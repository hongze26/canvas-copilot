# Canvas 扫描周次规则

时区、教学周起点和周次定义读取课程配置.md。首次由助手从学校日历与课程日程识别并记录，仍无法确定时请用户补充，不能猜测当前教学周；可先归档确定的常设信息。课程自己的周次、Reading Week与学期安排决定具体日程，不自行跳号。

只访问截至当前周的教学页面与附件。跨周资料如果当前周已明确使用，可以归档。全学期课表、常设说明、公告、作业、测验说明与项目总日程可读；明确属于未来周的教学附件仍受上限约束。

周一邮件覆盖当日周一到周日，可依据已发布课表给出未来七天安排，不额外访问尚未到周的教学页。首次教学计划也按可见正式日程整理，未知主题或时间标未公布。

课程采用单周或多周一组时，按实际教学安排归类并保留共用讲义。依据来源页面确定周次，不能仅凭文件名数字推断。
