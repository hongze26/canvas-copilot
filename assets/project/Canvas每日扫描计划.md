# Canvas 扫描计划

只在用户要求时手动扫描，使用课程配置.md中的课程和时区。周报随周一扫描发送，不创建独立定时任务。

1. 读取AGENTS.md列出的全部规则、总目录、各课Resource Index.md、库存与最近扫描及邮件记录。
   首次配置尚空时，先从已登录Canvas的Dashboard与全部课程识别当前在修课程，补全课程配置，创建各课目录及Resource Index.md。根据学校日历与课程正式日程确定时区和当前周；缺失事实集中请用户补充，继续可确定的常设信息。
2. 使用用户自己的已登录浏览器逐课检查开放栏目、当前周以内教学页及其关联资料。登录/多因素验证交给用户，继续可访问课程。
3. 对照URL、资源ID、标题、正文、链接及可见更新时间区分新增、已归档和变更。首次建立基线，不能将所有旧资料称为新发布。
4. 保存新增原文，制作中文版，按周归档，更新导航与库存。旧正文变更仅记录待确认。
5. 保存本轮Markdown和来源JSON，写明实际范围、当前周、资料路径、来源ID与待办。检查下载、排版、归类及受影响链接。
6. 按Canvas扫描邮件通知.md向本人发一封汇总，保存正文及回执。首次附教学计划；后续周一附当周安排。最终给出归档入口和发送结果。
